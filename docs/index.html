Flip Focus

A flip-clock focus timer that lives in the corner of your screen. Small window, always on top, around 60 MB of RAM. No account, no telemetry, no ads.

Download for Windows Source code

Windows 10 or 11, 64 bits. Unzip and run FlipFocus.exe. No .NET install needed.

Leave it in a corner and forget about it

Mini mode anchors the clock to any corner of your desktop, always on top, and it never steals focus while you type. Click it to start or pause, drag it to move it, right click for everything else.

What you get

  • Real split-flap digits that flip when they change.
  • A singing bowl, synthesised inside the app, at the end and the start of every session.
  • Three blunt quotes per session, with their author, that fade away on their own. Move the mouse over one and it goes.
  • Three notification states: never, only when the window is hidden in the tray, or always.
  • Global hotkeys that work from any program, and settings applied live.
  • Everything stored in a single JSON file. The app never connects to the internet.

Resource use

Measured on an 8-core Windows 11 machine, mini mode:

idle ................ 47 MB private   0.1 % CPU
running, flip on .... 61 MB private   1.8 % CPU
running, flip off ... 58 MB private   0.8 % CPU

Shortcuts

Space     start or pause          Ctrl + Alt + P    start or pause anywhere
Esc       leave fullscreen        Ctrl + Alt + M    mini / normal
F         fullscreen              Ctrl + Alt + F    fullscreen
M / N     mini / normal           Ctrl + Alt + C    restart cycle
A         settings                Ctrl + Alt + N    notifications on/off
C         restart cycle           Ctrl + Alt + H    hide or show window

Verify your download

Each release ships a SHA256SUMS.txt. For 1.0.0 the zip hash is:

DE34CC7DC4D45A223889F60564E3FF6151417FC8A1DBF4F05A43C000F76F369B

Check it with Get-FileHash .\FlipFocus-1.0.0-win-x64.zip in PowerShell.
